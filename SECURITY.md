# Security policy

This research prototype is not a complete anonymization system. Do not rely on its output to remove all personal data. Only the current default branch receives fixes.

## Report a vulnerability

Use GitHub's private vulnerability reporting at https://github.com/thoriqakbar0/redakt/security/advisories/new when it is available. If the form is unavailable, open an issue asking the maintainer to arrange a private channel. Include no vulnerability details, personal data, or credentials in that issue.

Provide a synthetic reproducer, the affected revision, expected behavior, and potential impact through the private channel. Do not include real personal data or secrets. Ordinary documented coverage gaps can be discussed publicly with synthetic examples.
