# Detection and weights

Use the [verification setup](README.md#how-to-run-a-pass). Run each row in a fresh invocation. The command snippets assume Bash from the repository root and a writable scratch directory.

| WGT-04 | P1 | Linux, redirected streams | Missing weights fail before stdin ([spec](../cli/weights.md#exit-immediately)). | Release binary and scratch directory. | 1. Run `r WGT-04 $'\xff' --weights "$scratch/missing"`. | Status 1, missing-model diagnostic, empty stdout. | pass |
